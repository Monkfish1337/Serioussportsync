Give AEW its own source, and remove "Check it works"

AEW now reads allelitewrestling.com instead of TheSportsDB. The free key
cannot reach AEW's upcoming cards at all - eventsnextleague returns one
event, eventsseason returns fifteen, and AEW runs about three weekly
tapings a week, so the fifteen are spent before February and every PPV
falls outside them. Three rounds of workarounds did not change that.

The site is Wix, which embeds its page data as JSON in a
<script id="wix-warmup-data"> tag, so this reads a structured collection
rather than scraping markup. Both pages: /events for what is coming and
/aewonppv for the replays, since /events alone leaves Recent empty.

Verified live through the real refresh path: 6 upcoming, 9 recent. All
Out 2026-09-26, Grand Slam France, WrestleDream, Fright Night, Full Gear,
Dynasty - every one with artwork. TheSportsDB had All Out on the 27th and
Full Gear on the 15th; releases are named by the local date, so the old
dates were wrong for matching too. TheSportsDB AEW stays selectable.

Two things broke on the switch, because the CMS names cards WITH the year
where TSDB did not. The query builder only added a query when the year was
missing, so "All Out 2026" produced one string. And the matcher kept words
of four characters or more and accepted on any single hit - "All Out" has
no word that long, so it matched every AEW release ever, and once the year
was in the name the only token left was "2026" and Full Gear matched an
All Out fixture. Both fixed, both pinned.

"Check it works" is removed - route, panel, client script, ranking hooks
and tests. It had to guess which fixture has a release; recency was the
only signal it had and recency is uncorrelated with availability, so on
working installs it picked things like a Friday practice session, found
nothing, and told the user their setup was broken. Two rounds of fixing
the guess did not fix the guessing. A check that cries wolf sends people
to debug configuration that was never wrong; Nuvio answers the same
question honestly, against something the user actually wants to watch.

528 unit tests plus both standalone verification scripts passing.
