Add a Big 3 folder and gather the discovered catalogs as Unmatched

Two new default collection folders, with artwork to match the existing set.

Big 3 -- NFL, NBA and MLB had no folder at all, so three of the busiest
promotions sat loose among the ungrouped catalogs.

Unmatched -- the seven discovered-* catalogs exist for events pulled out of
release listings that matched no promotion. Loose on the home screen they read
as seven more leagues with full schedules, which is the opposite of what they
are. Gathered into one folder they read as what they are.

Artwork: scripts/make-collection-art.py draws both tiles at 1672x941, the same
canvas as the four existing ones, to the same construction -- matte-black
subjects, orange rim light, a glowing hexagon behind, bloom, floor reflection,
vignette. Drawn rather than photographed, but built to sit in that row without
looking like a different product. Both are offered in the artwork picker on
the Configure step and the admin Collections page, so any folder can use them.

Reaching an install that already saved: a saved collections file replaces the
defaults outright -- that is what makes the editor work -- so a new default
folder would otherwise appear for nobody, since everyone has saved at least
once. Collections version 2 adds missing default folders by id, once, then
stamps the version. Folders the operator already has are untouched, renames
survive, and a folder they delete afterwards stays deleted rather than
returning on every load.

Two tests changed rather than were added: one pinned the four-folder layout as
the shipped default, and one used NFL as its example of an ungrouped catalog.
Both were describing the old arrangement correctly.
