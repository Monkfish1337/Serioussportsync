Three places the interface disagreed with itself

## The Server page called itself Admin

The nav rail says Server. The page heading said Admin, and its subtitle said
"manage users for this SeriousSportSync instance" -- about a quarter of what is
on it, alongside discovery pipelines, metadata keys, catalogs and appearance.
Heading matches the rail now, subtitle says what the page is for.

## The Event Editor printed the same two words twice

Every untouched row read

  Source date
  Source date
  2027-03-07

because the chip saying whether an event has been touched and the field saying
what the source gave were both labelled "Source date". Different facts. The
chip reads Unchanged or Overridden now.

## Match of the Day could not be configured at all

The only shipped promotion whose key had no field anywhere: it needs a TMDB
key, the Server page offered football-data.org and API-Football and nothing
else, and an install without TMDB_API_KEY in its environment simply showed no
events with no way to discover why. The new Events column would have surfaced
the symptom; the cure was still undiscoverable.

There is a TMDB field now, and a value saved there wins over the environment
variable the way the other two keys already do -- which needed the refresh told
about it as well as the field created, or the field would have saved a value
nothing ever read.
