Split "served" from "on the home screen"; label torrent rows; stop named

## Collections opened empty when home rows were disabled

There was only one switch. Turning it off removed the catalog from the manifest
entirely, and a Nuvio collection folder whose source is a catalog the manifest
no longer declares has nothing to show. showCatalogsOnHome was a single boolean
for all of them, so "keep this but not on my home screen" could not be said.
The only working procedure was: enable everything in SSS, then switch each row
off inside Nuvio by hand.

Two switches per promotion now. Served decides whether the catalog exists for
the client; Home row decides whether it also gets a row on the home screen.
Stored as hidden ids rather than shown ids, so a catalog added later appears by
default rather than silently not existing for everyone who saved before it.
All home rows / No home rows sit beside the existing enable-all pair, and the
step names the trap instead of leaving it to be discovered.

## Torrent rows now say which source found them

Nuvio already identified UU, DIY, Easynews and Sport-Video rows. Torrents were
the exception -- Bitmagnet, Prowlarr and the companion all arrived labelled
"TorBox" -- so "is Bitmagnet finding this, or Prowlarr?" meant reading server
logs. That is the question most worth answering in the client now the two run
together. Every source already recorded an indexer on the candidate; both the
playable row and the warm row surface it.

## Named TheSportsDB lookups were charged to everything

One request per name with config.tsdb.requestDelayMs between them to respect
the free key's 30/min: at the shipped 3000ms that is 42s for AEW's fourteen
names, on top of the existing calls, against a 60s interactive preview. A
preview that times out is worse than the empty Upcoming row this fixed.

Two gates. They run only when the list endpoints reached no future event --
the exact condition they exist for, so a healthy league pays nothing -- and
never during a preview, which is interactive and writes nothing.
