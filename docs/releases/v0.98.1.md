## 0.98.1 — 2026-09-13

Includes the measured MLB/NFL/NBA Prowlarr discovery queue and Review Aliases integration introduced in v0.98.0.

Fixes a discovery timer-boundary race found by CI: a deadline error now ends the query loop immediately. Queries that never start remain unattempted in alias evidence, and no extra query starts after a deadline expires.

Update to `ghcr.io/monkfish1337/serioussportsync:v0.98.1`. Manage the queue from Server → Direct Prowlarr → Manage Prowlarr discovery. Defaults are one search every 120 seconds, 100 SSS search/metadata requests per indexer per day, and a 30-day past-event window.
