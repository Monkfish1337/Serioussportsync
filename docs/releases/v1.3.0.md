This release makes discovery smarter, shows how much of what SSS finds you can
actually play, and adds a way to check TorBox Usenet on your own account.

## See what you can actually play

Coverage used to count a game as covered once SSS had saved a release for it.
That doesn't mean it plays: TorBox might not have it.

- **Discovery → Overview** now shows how many saved games TorBox has confirmed
  as cached, per league, alongside those checked and not cached and those not
  checked yet.
- **Diagnosis** shows the same figure and warns when fewer than half of a
  league's checked games are cached.

## Smarter discovery

- **No more wasted searches on indexers that ignore dates.** Some indexers,
  such as 720pier, answer a search like `MLB 2026.09.23` with their newest
  releases of any sport. SSS now notices, stops sending those indexers
  date-only searches, and uses team-name searches there instead. It shows on
  **Discovery → Prowlarr**.
- **Search now doesn't repeat itself.** Games played on the same day no longer
  run the same search over and over on the same indexer.

## Check TorBox Usenet

The **TorBox Usenet settings** page has a new **Check TorBox Usenet** button.
It checks your TorBox key and Usenet access, runs a search, downloads one NZB
and asks TorBox whether it has it, showing each step. Nothing is added to your
TorBox. If you have a TorBox plan with Usenet, please try it and share how it
goes in [this discussion](https://github.com/Monkfish1337/Serioussportsync/discussions/59).

## Prowlarr version warning

**Diagnosis** now shows your Prowlarr version and warns if it's one known to
break an indexer you use. Prowlarr 2.6.x rejects 720pier's torrent files, so
searches work but every download fails. If that happens, roll Prowlarr back to
2.5.2 and pin the version.

## Easier setup

New accounts now start **Configure** on an **Overview**: how SeriousSportSync
works, and how pressing **Refresh** within 30 seconds of opening an event runs a
full live search for new releases.

## For developers

`npm test` runs every suite CI runs, and line endings are now consistent on
every platform. A test that failed at random has been fixed.
