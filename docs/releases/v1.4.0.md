This release refreshes the admin pages, tells you when something breaks, shows
each account when its own TorBox key or Easynews login stops working, and
replaces the old fallback artwork.

## A cleaner admin

- **Discovery, Promotions and Server** are rebuilt. Each page opens with its
  status and key numbers, then the actions, with history and settings folded
  away. A folded section says what it holds, so you can see how things are set
  without opening it. Long lists scroll inside their own box instead of
  running down the page, and descriptions are one line.
- **The sidebar** is grouped by job (Health, Sources, Content, System), its
  items are proper buttons with icons, and it collapses to icons only. Your
  browser remembers the choice.
- **Promotions** is one list: each promotion, its source and its events, with
  **Review aliases** on the row and everything else under **More**.

## Know when something breaks

- **Alerts.** Server → Alerts sends problems from Diagnosis to a Discord,
  Slack or plain JSON webhook: once each, and again when they clear. It checks
  every 30 minutes, can be limited to critical problems, and can send a daily
  summary at a time you choose. **Save and send test** checks the webhook
  works. The webhook URL is stored encrypted.
- **A source that stops listing games is flagged.** When a league's feed
  suddenly lists far fewer upcoming games than a day earlier, Diagnosis shows
  it under Schedule. Games already saved stay listed when a feed drops them,
  so until now nothing noticed.
- **A refused key shows on the account.** If TorBox refuses an account's API
  key, or Easynews its login, during a real search, that account's Configure
  page shows **Key refused** or **Login refused** on the service, with when it
  happened. Diagnosis → Playback names the account. It clears on the next
  search that works, or when the key is changed.

## Smarter discovery

- **Searches learn from what worked.** Each indexer's searches are tried in
  the order that has found releases on it before. Searches are compared by
  their shape, so short team names that work for one game are tried first for
  the next.
- **A series is saved in one search.** When a team search returns a whole
  series, SSS now fetches one torrent for each game still missing a release,
  up to six, instead of the three best-seeded, which were often the same game.

## New fallback artwork

Events without their own poster now show a plain card with the promotion's
name, in the same style for every promotion, instead of TheSportsDB banners
and badges from 2014–2020. Boxing gets a portrait card and the team sports
square ones. Events that had an old banner saved show the new card too.
