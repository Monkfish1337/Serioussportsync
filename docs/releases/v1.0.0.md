# SeriousSportSync v1.0.0

SeriousSportSync v1 brings the metadata calendar, torrent discovery, live search
providers and account configuration together as one self-hosted sports addon for
Stremio and Nuvio.

## Discovery and coverage

- One Discovery workspace now reports recent torrent coverage and gives
  Prowlarr, Sport-Video and Bitmagnet their own promotion selections, schedules,
  progress, diagnostics and controls.
- Prowlarr has a slow measured queue with durable daily budgets, indexer
  cooldowns, retry history, saved event matches and optional live search. The
  Improve Matching lab remains available when live playback search is disabled.
- Bitmagnet provides the general background preparation path. Sport-Video has a
  separate sequential preparation worker. Usenet Ultimate and Easynews remain
  fast live responders and create no background search load.
- Review Aliases records real query outcomes, including hits, zero results,
  timeouts and never-started searches. Manual torrent-resource matching can add
  a confirmed event result directly to the local database.
- Discovery coverage counts usable torrent identities only. Disabled,
  account-specific and Sport-Video-derived catalogs no longer distort the
  seven-day overview.

## Catalogs and matching

- Twenty-five built-in promotions include UFC, ONE, WWE and AEW events, weekly
  WWE Raw, SmackDown and NXT, weekly AEW Dynamite and Collision, Formula 1,
  boxing, MotoGP, Match of the Day, UCL, Premier League, MLB, NFL and NBA.
- Weekly wrestling dates are normalized to their actual local air date, with
  bounded metadata gap recovery and strict show/date release matching.
- Each promotion can set its own metadata start date, reducing slow free-tier
  provider work and keeping irrelevant history out of catalogs.
- My Teams materializes the complete team roster once, then lets each account
  add or remove team catalogs independently. Team art is square and generated
  team promotions stay out of the main Promotions workspace.
- Matching supports compact dates, scene separators, common team aliases,
  three-letter codes, American league week formats and overnight date edges.

## Administration and clients

- The five-step Configure wizard supports account-specific catalogs, home-row
  visibility, collections and teams. Collection folders can be pinned and use
  consistent bundled artwork.
- Server, Discovery, Promotions, Event Editor, Collections, Metadata, User
  Management, Database, Logs and Backup have dedicated pages with sortable,
  filterable tables and clearer text navigation.
- Administrators can approve or decline access requests. DIY Usenet settings and
  server-intensive actions are restricted to administrators.
- Server time zone is configurable, metadata keys and forced refreshes live on
  Metadata, and event date overrides survive provider refreshes.
- The default container is bound to localhost, runs read-only and unprivileged,
  has resource and log limits, exposes a health check and supports trusted proxy
  settings for a published Cloudflare tunnel.

## v1 validation

- Live seven-day coverage at release review was 127 of 132 eligible events with
  saved torrent identities (96.2%).
- All 648 automated tests passed, along with account configuration, Nuvio schema,
  backup/recovery, dependency audit, Compose health and release-container checks.
- The dependency audit reported zero known production vulnerabilities.
- Representative Nuvio playback was confirmed locally and through a Cloudflare
  tunnel. Cached stream requests observed during review completed in 71–408 ms.

Update to `ghcr.io/monkfish1337/serioussportsync:v1.0.0` or use `latest` after
the release workflow completes. Existing data and settings are migrated in place;
take an admin backup before upgrading.
