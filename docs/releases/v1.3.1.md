Fixes from checking 1.3.0 on a live server.

## Cached on TorBox is now measured

1.3.0 added a "Cached on TorBox" figure, but TorBox was only asked when someone
opened an event, so most saved releases showed as "not checked yet". SSS now
checks saved releases in the background, read-only, every 30 minutes using an
administrator's TorBox key. The figure on **Discovery → Overview** and in
**Diagnosis** fills in within the hour after updating. Nothing is added to
TorBox.

## Fewer indexers wrongly marked as ignoring dates

1.3.0 learns which indexers ignore dates in searches. It was too quick to
decide: an indexer that simply had nothing posted for a day could be marked.
Now only an indexer that answers with releases from other days is marked.
Existing marks are cleared once and re-learned.

## Check TorBox Usenet checks your plan

**Check TorBox Usenet** now reads your TorBox plan and tells you if it doesn't
include Usenet downloads (they need Pro). Before, it could pass on any plan.
