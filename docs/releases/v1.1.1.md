# SeriousSportSync v1.1.1

A small release with one new sport: **the NHL**. It also brings a fix for F1
practice sessions and better visibility on how searches perform.

## NHL

- **NHL is built in.** A new catalog comes from ESPN's schedule, the same feed
  behind NFL and NBA, with team logos as artwork.
- **Follow your team.** NHL teams are now in **Configure → Your teams**,
  alongside Premier League clubs and NFL, NBA and MLB teams.
- **Matching knows all 32 teams:** full names, nicknames (Maple Leafs,
  Golden Knights), cities, three-letter codes and common short forms (Habs,
  Leafs, Caps, Avs, Bolts). "Utah Hockey Club" still matches last season's
  Utah releases.

Thanks to everyone in [Discussions](https://github.com/Monkfish1337/Serioussportsync/discussions)
who asked for it.

## Fixes

- **F1 practice sessions match the right session.** Practice 1, 2 and 3 were
  treated as one session when matching, so opening Practice 3 could offer
  Practice 1 and 2 releases. Each practice now accepts only its own number
  (`Practice 3`, `Practice.Three`, `FP3` and Russian forms). Searches ask for
  that session first, and bundles of all practices still appear.
- **Backups work on Windows hosts.** The admin **Backup** download failed when
  SSS ran on Windows.

## Better visibility

- **Review aliases includes My Teams searches.** Matches opened from a team
  catalog, such as Man United, are now shown on the league's page, labelled
  with the team. League rules apply to them as well. Before, those searches
  were recorded but shown nowhere.
- **Sport-Video variant count.** The Sport-Video tab shows how many pages
  offer more than one torrent, for example 1080p and 4K. It measures whether
  keeping every quality variant is worth adding.

## Community

SeriousSportSync now has

Ask setup questions in Q&A, suggest ideas and show off your setup. Issues now
use forms for bug reports and feature requests.

## Upgrading

```bash
docker compose pull
docker compose up -d --remove-orphans
```

No settings need changing. NHL appears in **Configure → Catalogs** and
**Your teams**. To have the Prowlarr queue search NHL games in the background,
add it under **Discovery → Prowlarr**.
