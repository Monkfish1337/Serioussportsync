# SeriousSportSync v0.96.0

This release improves live search coverage and makes SSS retain useful discoveries without treating incomplete searches as finished.

- Background availability discovery stays **Bitmagnet-only**. Full live searches use a separate cache, so preparation cannot suppress Prowlarr.
- Prowlarr torrent-hash retrieval uses the configured timeout within the discovery budget. Partial results from Prowlarr, Bitmagnet and Easynews remain usable and are retried rather than frozen in a complete-search cache.
- Matching live torrents are stored individually. TorBox cache confirmation makes them reusable for that account, including after a later Prowlarr failure.
- Prowlarr's bounded MLB/NBA/NFL queries include nickname pairs, full names and `@` variants; NFL week queries receive a slot when metadata is available. UCL keeps its specialist query order.
- Known playable torrents stay visible when larger uncached releases are discovered. Confirmed Easynews/native Usenet results no longer prevent discovering alternatives.
- Matching Lab now includes direct Bitmagnet and torrent Prowlarr. It shows source queries, timing and partial status, and can use the saved live promotion rules or explore draft rules.
- Empty searches for recently completed events refresh after five minutes.

## Timing settings

In **Server → Discovery timing**, Easynews now has its own query count and timeout controls. Defaults are six variants and five seconds per query, bounded by the request budget.

**Fast response wait** defaults to **0**, preserving thorough searches and existing saved request/Prowlarr limits. Set it to **8000** to return completed results after roughly eight seconds while other bounded live searches learn candidates for the next refresh. If no results have arrived then, SSS keeps waiting within the request budget. A response cannot gain additional rows after it has been returned.

## Validation and upgrade

All 540 unit tests, the Nuvio collection checks and account checks passed locally. New regressions cover partial-cache prevention, shared deadlines, matchup diversity, confirmed-result ranking, fast/thorough responses, recent-event expiry and live Matching Lab queries.

Use `ghcr.io/monkfish1337/serioussportsync:v0.96.0`, or update `latest` once the container workflow completes. Recreate the SSS container while retaining its existing data volume. No database wipe or migration is needed. Older search cache scopes refresh on demand.

The Bitmagnet video-only facet and thirty-day default fixture history remain operator choices. This release does not automatically broaden historical catalogs or override that filter. Tests establish orchestration and matching behaviour; actual coverage still depends on releases present in the configured sources.

This tag also includes the catalog, account and matching improvements already merged into main since v0.95.0.
